# Codex 设定文件规范

## 目录归位（铁律）

- 设定/规则类 `.md` **一律放 `StoryLine/逆世书/Codex/<类目>/`**。启用索引的类目以 `逆世书/System/codex-categories.json` 为准。
- **`System`（单数）是 StoryLine 插件的数据目录**（`plotgrid.json`、`plotlines.json`、`codex-digests.json` 等），**禁止往里放 `.md`**——放进去不会被 Codex 索引，等于文件失踪。
- 规则不分单本：`逆世书/Codex/Systems/` 为全本共用；单本级 `<本>/Codex/Systems/` 保持空置，不往里放规则。
- 新建 Codex 条目必须写 frontmatter，至少含 `type`（如 `systems`）、`name`、`description`；没有 frontmatter 的文件不会被正确索引。

## 命名规范（铁律）

**格式：`<范围前缀>·<主题>.md`**，范围前缀三选一：

| 前缀 | 适用 | 例 |
| --- | --- | --- |
| `全本·` | 跨本通用 | `全本·力量体系`、`全本·世界架构`、`全本·势力组织` |
| `本一·` | 只属某一本（今生＝本一） | `本一·世界规则`、`本一·掉马风险源` |
| `本一卷一·` | 只属某本某卷 | `本一卷一·系统任务设定`、`本一卷二·系统任务设定` |

- **重名即歧义**：曾出现 `世界架构`／`文化习俗`／`势力组织` 各有全本版与本一版、文件名完全相同，导致 `[[世界架构]]` 指向不可预测。加前缀即为消歧义。
- **适用范围**：Systems / Lore / Culture / Organizations 等**设定与规则类**条目。Characters、Locations、Items 用专名（`[[许默]]`、`[[滨海·酒吧]]`），**不加范围前缀**。
- **行内术语必须配 alias**：若文件名会被当作行内词写进正文（如"[[主角]]判断现实的基准"），改名后必须在 frontmatter 加 `aliases`，让链接仍能写 `[[主角]]`。否则正文会被批量改写成 `[[全本·主角]]`，严重破坏可读性（曾影响 169 处／48 文件）。
- **改名通过 Obsidian 应用内操作（界面、插件或 CLI）**（见根目录 `AGENTS.md`「全库铁律」）。改完必须审计——**歧义链接会被全部解析到其中一个同名文件**，需逐条核对指向是否符合本意。

## 单一事实源（铁律）

**同一个事实，全库只允许在一个文件里写全；其余位置一律用 wikilink 指过去，不得复述。**

- 判定"同一事实"：同一条数字、同一个时间点、同一条机制口径。例：变身冷却时长、某奖励金额、某能力的解锁时机。
- 写之前先搜一遍该事实是否已有主场；有主场就只写 `见 [[主场文件]]「小节名」`。
- 主场归属按"谁是这件事的机制主人"判定，不按"谁先写的"。例：变身冷却的主场是 [[本一·系统设定]]「伪装/变幻 规则」，奖励机制段只指路。
- 复述会导致改一处漏两处——曾出现"5/15解锁＋酒吧首次真用"同时写在三处、冷却口径在两处互相矛盾的事故。
- 例外：视角不同的交叉引用可保留（如"机制"与"风险"两个角度各写一次），但必须互相指路。

## 规则层 vs 清单层

一个文件只装一种性质的内容，混装会导致改动时找不到东西：

| 性质    | 判断标准     | 归属                                            |
| ----- | -------- | --------------------------------------------- |
| 约束类规则 | 违反了就是写错  | `[[本一·系统设定]]`、`[[本一卷一·系统任务设定]]`、`[[本一·世界规则]]` |
| 设定事实  | 背景真相，极少改 | `[[本一·穿越与分身设定]]`             |
| 产出清单  | 随写作进度天天变 | `[[本一·掉马风险源]]`             |

## 人物卡：字段与正文分工

- StoryLine 人物字段装得下的内容只写字段，正文不再复述：称呼（nickname）、年龄（age）、定位（role）、职业（occupation）、住处（residency）、外貌（appearance）、特征（distinguishingFeatures）、穿着（style）、小动作（quirks）、性格（personality）、内外动机、长处、缺点、恐惧、信念、误信（misbelief）、成长经历（formativeMemories）、成就与失败、秘密、起点、目标、预期变化、习惯（habits）、随身物（props）。
- 人物关系的类型只登记在 `relations`；正文只写关系怎么发展、分时接触。
- 正文只写字段装不下的：关系进程、出场时序、剧情作用、结局、台账、写法约束。
- 人物内核：核心逻辑写 `belief`，反差写 `flaws`，盲区写 `misbelief`；衍射写正文「行为方式」。
- 字段写纯文本，不写 wikilink。
