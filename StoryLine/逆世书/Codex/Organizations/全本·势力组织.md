# 势力组织

> 来源：《羽衣》世界设定 + 早期 WAIC 创作。提供第一世（仙界）和第二世（灵界）的宗门、国家架构。

## 宗门势力（仙界/灵界）

修仙世界中有多个门派，各有独特之处。为首的是**三大宫、六大门**。

### 专精矩阵（三系分布总览）

对齐 [[全本·力量体系#修炼体系]] 三大派系（锻体/炼魂/铸灵）：**三大宫各占1系100%，六大门1精1辅**，三系两两组合共6种排列、互不重复。

| 势力   | 主修（精）   | 辅修                   |
| ---- | ------- | -------------------- |
| 琼华宫  | 炼魂 100% | —                    |
| 罗浮宫  | 锻体 100% | —                    |
| 天机宫  | 铸灵 100% | —                    |
| 御灵宗  | 炼魂      | 铸灵                   |
| 合欢宗  | 锻体      | 炼魂                   |
| 藏剑山庄 | 铸灵      | 锻体                   |
| 玄武门  | 锻体      | 铸灵                   |
| 左风堂  | 铸灵      | 炼魂                   |
| 妙清山  | 炼魂      | 锻体（医术治愈本质是精神力驱动身体恢复） |

宗门规模与县/府/都行政层级的对应关系见 [[位阶数据]]。

### 三大宫

---

#### 琼华宫

| 项 | 内容 |
| --- | --- |
| **所在地** | 琼华峰，常年云雾缭绕，仿佛仙境 |
| **建筑风格** | 白色玉石建造，雕刻精美，透露女性修士的柔美与细腻 |
| **服饰风格** | 素白长裙，外披淡粉色轻纱，腰间束以流苏飘带，清新脱俗 |
| **门派标记** | 一朵盛开的玉兰花（象征高洁与纯净） |
| **特点** | 全是女性修士，以**炼魂**为主修，擅长操控灵魂之力；极为护短，门中弟子受欺必站出来 |
| **擅长领域** | 灵魂操控、灵魂攻击与防御、灵魂治愈术 |
| **掌门** | [[苏依伊]]（羽衣仙子），接任前掌门 [[苏瑶卿]]。掌门单系一对一传承 |
| **掌门权责** | 掌门是琼华门面，日常事务由长老管事；掌门资源供满、权力第一。掌门有命劫 |

**背景故事**：琼华宫由一群对炼魂之道有极高追求的女性修士共同建立。她们厌倦修仙界纷争与虚伪，选择在山上建立修炼净土。经数代人努力，成为炼魂学派代表。

**门派区域**：
- 琼华峰（掌门住所）、琼华殿（主殿，峰顶）、玉心殿（南·半山腰，日常事务）
- 静谧峡（东北·闭关修炼）
- 晨曦峰（东·内门弟子住所）、玉灵殿（晨曦峰顶·修炼核心）、月华台（晨曦峰顶·大型集会）
- 百草林（东南·珍稀灵木仙草）
- 灵隐湖（西北·低洼地带，清澈见底）、玉兰洞府（灵隐湖底·历史与文化传承）
- 飞云峰（西·长老所在地）
- 碧云居（西南·外门弟子住所 / 山门入口）

**位阶架构**：

| 位阶    | 修为要求      |
| ----- | --------- |
| 记名弟子  | 仅限女性、炼体、凝气 |
| 外门弟子  | 筑基        |
| 内门弟子  | 金丹、元婴     |
| 执事    | 分神、合体     |
| 首座    | 大乘、渡劫     |
| 长老/掌门 | 飞升/半仙、真仙  |
| 大长老   | 上仙        |

**组织架构**：
- **长老团**：应对大事件，由修为最高、经验最丰富的长老组成，平时隐居修炼，仅大事件时出面
- **玉心堂**：处理日常事务（弟子管理、资源分配等），由擅长管理的修士组成
- **玉灵殿**：专注修炼及特殊任务，负责探索新修炼法门、研究灵魂操控高级技巧

**琼华宫人物**：
- [[苏依伊]]（羽衣仙子）— 现任掌门
- [[苏瑶卿]] — 前掌门
- 清微、苍古、和阳、幽玄、净明、孤绝、清冷 — 长老/同门

#### 罗浮宫

| 项 | 内容 |
| --- | --- |
| **所在地** | 巍峨山脉最高峰，俯瞰众生万象 |
| **建筑风格** | 青石和木材建造，古朴庄重，坚固耐用 |
| **服饰风格** | 灰色僧袍，腰间系黄色布带，简约大方，透出坚毅果敢 |
| **门派标记** | 一尊金色佛像，面容慈悲，手结法印（象征正义与善良） |
| **特点** | 修仙界最为正义的门派，以**锻体**为主修，注重身体锻炼与强化，近战中无往不胜。行走江湖秉持正义之心，惩恶扬善，深受百姓爱戴 |
| **擅长领域** | 近战格斗、身体强化 |

**背景故事**：罗浮宫源于一位高僧的悟道。他深感世间邪恶横行、正义缺失，决定创立罗浮宫培养正义修士。

#### 天机宫

| 项 | 内容 |
| --- | --- |
| **所在地** | 神秘岛屿，四周环绕浓雾和暗礁，与世隔绝 |
| **建筑风格** | 黑色玄铁和奇特石材，坚固且充满神秘气息 |
| **服饰风格** | 黑色紧身衣，外披深紫色斗篷，神秘莫测 |
| **门派标记** | 一枚银色齿轮，刻满复杂符文（象征机关术和秘籍的深厚造诣） |
| **特点** | 修仙界最为神秘的门派，藏有大量秘籍和财富。以**铸灵**为主修，擅长研制各种神奇法器与机关。行事诡秘，但总能在关键时刻拿出令人惊叹的法器扭转战局 |
| **擅长领域** | 法器研制、机关术、秘籍收藏与传承 |

**背景故事**：天机宫可追溯到修仙界远古时期。一位对铸器之道有极高造诣的大能者创立，将铸器秘籍和财富留给后人。经无数代人积累，成为修仙界最富有的门派之一。

**第三本关联**：男主（[[苏依辰]]）专属天道线复活对象"老爷爷"即出自本门（人魂锚定 [[九玉]]·戒指），见 [[第三本世界规则·天道线]]。

#### 御灵宗

| 项 | 内容 |
| --- | --- |
| **所在地** | 广袤森林深处，古木参天，野兽出没 |
| **建筑风格** | 木材和藤条建造，与自然环境融为一体 |
| **服饰风格** | 绿色长袍，腰间束兽皮腰带，自然朴素 |
| **门派标记** | 飞翔的凤凰（象征祥瑞与和谐） |
| **特点** | 在炼魂之道上有极高造诣，擅长与灵兽或妖灵建立深厚灵魂联系。每位修士寻找一只心性相合的灵兽共同修炼、心意相通。灵兽就是他们的全部，是最亲密的伙伴和战友 |

**背景故事**：由一群热爱自然、崇尚与灵兽和谐共处的修士创立。他们认为与灵兽建立灵魂联系可更深入理解天地之道。

#### 藏剑山庄

| 项 | 内容 |
| --- | --- |
| **所在地** | 险峻山峰之上，峭壁千仞 |
| **建筑风格** | 青石和木材，古朴典雅 |
| **服饰风格** | 青色长袍或灰色劲装，腰间佩戴各式剑器或剑饰 |

| **擅长领域** | 灵器研制、剑法修炼、身体强化 |

**背景故事**：一位痴迷剑道的修士游历四方寻求极致铸剑之法，偶然发现隐藏强大剑气的险峻山峰，在此建立山庄。后世尊其为"剑神"。

##### 教派层级·小宗门（第三本[[主角]]出生地）

第三本[[主角]] [[苏依伊/苏依辰]] 出生地——小县城——所属的入门宗门，是**藏剑山庄下下级、教派层级**的小宗门（不是藏剑山庄本体），凝气期即可入门直接称"弟子"（见 [[力量体系·位阶数据]]）。名字⏳占位待定。地理上与东山城隔山相望，位于山西面，紧邻小县城，骑马半天可达（见 [[经济货币·地理]]）。[[主角]]在此完成 [[比武考核（入门弟子）]] 入门，后续 [[入中流门派]] 才离开此地升入更高层级宗门，最终归入 [[琼华宫]]。

## 国家势力

### 上三国

| 国 | 特点 |
|------|------|
| 琼林郡 | 琼=美玉，林=树木丛生。自然资源丰富，地域美丽如林中之玉 |
| 玉澜国 | 玉=高贵纯洁，澜=波涛。历史如波澜壮阔的江河，璀璨如美玉 |
| 璇玑域 | 璇玑=天上星辰。天命所归，拥有广袤领土 |

### 下三国

| 国 | 特点 |
|------|------|
| 凤仪朝 | 凤=吉祥之鸟，仪=仪态。国运吉祥，仪态庄重 |
| 翰墨邦 | 翰墨=书法文学。文化底蕴深厚，重视文化教育 |
| 琅华境 | 琅=美玉，华=繁荣。商贸繁荣，地域辽阔 |

### 列国

| 国 | 特点 |
|------|------|
| **玉笛乡** | 玉笛=音乐文化。悠扬的文化和艺术氛围 |
| **锦绣域** | 锦绣=美丽富饶。地域美丽且经济繁荣 |
| **琉璃界** | 琉璃=美丽材料。如琉璃般美丽，疆界清晰 |
| **晟朝** | **半岛之心**，深厚文化底蕴和丰富自然资源。连接大陆内部与半岛两国的桥梁。**第二世故事核心发生地** |
| **武朝** | 半岛一侧，三面环海，尚武精神。渴望向大陆扩张，吞并晟朝是其关键目标 |
| **燕国** | 半岛最强国，与大陆内部相连。采取远交近攻策略，在半岛发挥重要影响力 |
