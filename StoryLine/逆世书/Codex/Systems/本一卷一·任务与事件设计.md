# 卷一 · 任务与事件设计

> **这是产出清单，不是规则**——排期与挂点随写作进度变动。任务机制的硬约束见 [[本一·世界规则]]。

## 任务线

[[一伶]]以"人生赢家系统"为伪装。任务表面上帮助 [[许默]]改善现实生活，实际用于在源界允许的范围内逐步恢复身体、仙器和记忆。

### 设计原则

1. 初期任务必须像现代生活改善计划，不直接暴露修仙背景
2. 资金奖励只缓解生存压力；身体、精神和技巧奖励为[[主角]]提供处理问题的条件，现实矛盾由他的行动、选择与他人协助解决

> 资金实际来源见 [[本一·世界规则]]「资金直入」。

## 第一卷 · 转化弧线设计

### 两条转化主线

**A · 被动线：体魄优化**

随系统能力逐步开放，[[主角]]现实身体不断改善：增强生命形态（变身，见「系统能力总览」）、身体强化（体魄＋恢复，两种形态共享）。[[主角]]视角：以为是系统带来的现实逆袭，不知女身是妹妹的原身，也不知道系统正在同时唤醒姐妹两人。

**B · 主动线：思维转变（变身态度弧线）**

对「变身/女身」的心理弧线：**抗拒不用 → 不得不用 → 偶尔用 → 需要就用**。第一卷只写“把女身当工具使用”的态度变化；永久性转落在第三卷与女性仙体归一。

**C · 自信成长线**

[[主角]]的拘谨与退让来自债务、失败经历与怕牵连工作和家人的顾虑，不是天性。随系统能力、收入改善与新的社会关系积累，自信按“怕承担不起后果 → 条件改善 → 尝试表达和争取 → 成功经验积累”推进：卷初不愿成为焦点、冲突先求息事宁人；共身期女身的新身份暂时摆脱旧评价，逐渐敢表现、敢拒绝、敢谈条件。成长最终须回流至男身的工作和旧关系，保持同一行动意识的连续性。性格基调、两身份差异与欲望边界见 [[许默]]、[[苏晚]] 人物卡；卷一挂点落在各事件卡“侧写挂点”栏，跨卡递进在 [[第一卷卷纲]] 挂点索引登记。

### 过渡事件设计原则

- 驱动力是**避险**（不变→大麻烦）；女身是功能性身份多一个可用
- 身份不绑定＋[[主角]]必须亲自做＋须用非[[许默]]身份完成＋避开正式机构；须发生在增强生命形态首次实际使用（[[酒吧·苏晚撞王屿]]）之后
- 事件除推进工具化弧线，还要让女身（[[苏晚]]）逐步接触社会、攒出关系网，为第二卷起"成为真人"铺路。常见结构：一次被迫变身 → 留下需持续用女身的后果 → 关系网生长
- 节奏分配：抗拒期1-2个 → 不得不用期3-4个 → 偶尔用期2-3个 → 需要就用期1-2个
- 变身的冷却/消耗细则：见「伪装/变幻 规则」
## 三线在卷一的落点

> 机制本身见 [[本一·世界规则]]；本节只记卷一的具体排期与挂点。

### 身体线

- 固定周期只在开篇（5.14–5.29）显性使用，作用是让[[主角]]逐步建立对系统的信任；信任建立后转入背景，不再逐条写出，但机制仍在运转，维持钱与日常生活的连续性。
- 「全勤奖」是[[主角]]在首次漏跑、奖励资格取消后依据[[苏文君|母亲]]单位旧事形成的理解，此时他尚不知道该周期的确切金额。
- [[主角]]直到 5/18 才找到并激活旧卡，这是首月仍然逾期的直接原因之一。

### 爱情线（学习任务）

- **首发（5/24 晚）**：【学习任务发布：熟记次日收货与搬运流程。】【书中自有颜如玉。】——先于[[周海]]安排次日搬样品，构成系统预知的失态点。
- **难点即戏**：[[主角]]高中之后没再正经学过东西，第一晚只能硬啃理论、坐不住；次日 5/25（[[身体变化·周海察觉]]）在实际搬货中实践掌握、当场播报完成。
- **链条第二发**（单证方向）于 5/25 完成时当场发布。
- [[主角]]的固定反应："这也算爱情？！"

### 增强生命形态

- **第一次尝试（非真用）＝ 拿到礼包当场（5/15，[[首次结算·增强形态]]）**：问「增强什么」无回答，当场试着启用，不触发——他连怎么用都不知道。
- **第二次尝试（非真用）＝ 首个学习任务那一场（5/24）**：学不进去 → 又想起「增强生命形态」、指望它能帮上忙 → 念头动了一下、最终没有真的启用 → 「换个身体」的念头在此埋根。[[酒吧逃堵·首次变身]]那次才是孤注一掷。
- **不另设催收虚惊场**：不可使用[[张长龙]]踩点——5/14 夜堵后对方认定[[主角]]腿断（[[巷中醒来·异常复原]] 那声"咔"），这份误判是 6/3 他「听说许默在酒吧、觉得不可思议才亲自去看」的前提，不能提前作废。

## 金额链校验

> 正文里出现的每一个金额都必须和这条链对得上；改动任一奖励数字都要回来重算。

- **现行硬数字**：5/15 首跑 1000 → 5/22 首消 500 → 5/29 结算 2000（身体500＋爱情1500）→ **累计 3500**；6/3 还借款机构逾期 2200、转[[苏然]] 200 → **余 1100**。
- 该余额不敢动的理由：[[主角]]月薪 3500，10 号要付[[程辉]] 2000 ＋ 高利贷 1800 ＝ 3800，工资本身不够。
- **账本是专用道具**（日常剧情不引入）：债务栏缩短、系统栏变长＝[[主角]]的生活编年史；远期坑位——[[苏晚]]侧开销无法并账（"算谁的？"）。
