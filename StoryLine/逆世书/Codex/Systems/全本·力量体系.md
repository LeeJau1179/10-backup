## 修炼体系


### 早期修炼教育体系

> 灵界凡人子弟从识字到入宗的标准化路径。九岁为关键分界点。正常修炼年龄9岁。提前修炼需满足①家族专属功法，②有大能全程协助，二者皆无则强行提前修炼轻则灵根受损、重则沦为凡人。

| 阶段        | 年龄段   | 内容                                                            | 类比      |
| --------- | ----- | ------------------------------------------------------------- | ------- |
| 学前教育      | 0–8岁  | 识字、算术、灵界常识、基础体能。由家庭或地方塾堂负责                                    | 小学      |
| 灵感觉醒仪式    | 9岁    | 各地门派对辖区适龄孩童统一举行，明确自身灵根，同时领取基础引气功法，正式进入**炼体期**                 | 入学考试    |
| 家庭/地方修习   | 9–11岁 | 在家中或地方修习场所练习引气、巩固炼体基础。有天赋者会接受进一步指导                            | 初中      |
| 宗门入门考核    | 11岁前  | 达到**凝气期**即可参加所在区域上游宗门考核，通过后正式入门。区域对应关系见[[全本·势力组织]]宗门层级           | 中考/高中入学 |
| 分支选择（凝气后） | 入门后   | 宗门内设有对应修炼派系的分支，弟子根据自身灵感属性和意愿选择方向。宗门内**强势分支**一般以该地域上游宗门的主修派系为主 | 文理分科    |

> 例：第三本[[主角]]出生地的上游宗门为 [[藏剑山庄]]（主修铸灵、辅修锻体），故该地域宗门分支以铸灵和锻体两系为主；[[主角]]后入[[琼华宫]]（纯炼魂）则属跨体系转向。

**宗门晋升路径**：
- 入门后以灵气大小、境界为基础，通过内部考核逐级晋升（记名→外门→内门→执事→首座→长老）。
- **小宗门可推荐优秀弟子前往大宗门**，获取更优资源与晋升空间；弟子也可主动申请前往大宗门深造。
- **第三本[[主角]]出生地**——小县城的上游宗门为 [[藏剑山庄]]，[[主角]]入三大宫/六大门之前曾在藏剑山庄下下级、教派层级的小宗门停留（名称⏳占位待定，见 [[势力组织·小宗门]]），后方入[[琼华宫]]。

> 位阶对照：[[全本·力量体系#位阶数据]] 中的宗门层级（记名→外门→内门→执事→首座→长老）即为入门后的晋升通道；[[全本·势力组织]] 中各宗门的修为要求为晋升门槛。

### 灵界生灵/魔修炼等级（从低到高）

| 境界    | 说明                                                      |
| ----- | ------------------------------------------------------- |
| 炼体期   | 引导自然灵气入体锤炼自身，增强生命力与体魄。灵气锻炼不只局限于肉体，也可能是意识，灵气的引导技巧等       |
| 凝气期   | 引导自然灵气留存体内。区分修行者和普通人的第一道坎，需资质、家族传承或机缘                   |
| 筑基期   | 建立修为基础，形成基台储存另气。需专门功法或秘术                                |
| 金丹期   | 将灵气凝聚成金丹，寄宿于丹田                                          |
| 元婴期   | 金丹升华成元婴，形成独立法力实体                                        |
| 分神期   | 将神魂一分为二，增强感知与行动能力                                       |
| 合体期   | 重新合并神魂，提高神魂力量与灵活性                                       |
| 大乘期   | 感悟天道（天道实际也是仙人创造的一种法则）                                   |
| 渡劫期   | 经历生死考验，提升修为。对于「鬼」而言，这是最后的考验——成功转化为「人」或「妖」者或可渡过此劫，否则魂飞魄散 |
| 飞升/半仙 | 「人」与「妖」通过渡劫后的境界，准备脱离灵界升入仙界                              |

### 修炼派系

达成凝气大圆满后，晋升筑基需专门的功法或秘术。功法/秘术分为三大派系：

| 派系       | 核心             | 擅长                                             | 典型代表                                                                                                                                            |
| -------- | -------------- | ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **锻体派系** | 以灵气强化身体        | 近战格斗、拳脚、兵器等近战技巧。在炼体基础上进一步挖掘身体潜能，身体力量、敏捷和防御达到极致 | [[罗浮宫]]、[[玄武门]]、[[藏剑山庄]]                                                         |
| **炼魂派系** | 以灵气强化灵魂力       | 感知、幻术、灵魂冲击等灵魂攻击与操控。通过灵气滋养灵魂，可干扰敌人心智或直接伤害灵魂     | [[琼华宫]]、[[御灵宗]]                                                                                       |
| **铸灵派系** | 以灵气制作灵物（物品或动物） | 灵器的炼制与运用。可增强攻击力、防御力、辅助能力等，全方位增幅                | [[天机宫]]、[[藏剑山庄]]、[[一伶]]/[[七玥]]/[[九玉]]（仙器） |

### 说明

#### 年龄/战力
寿命上限与战力的综合折算值。以普通人为基准（寿命 80 岁、战力 1），炼体期寿命约 100 岁、战力约 1.6。数值越高，对应境界的个体实力越强。

#### 人口基数
该境界修炼者在大众中的比例。数值为「每 X 人中出 1 人」，如炼体 10:1、筑基 10000:1、元婴 10000000:1。合体及以上留空——已超出凡世可统计范围。

#### 村落等级
该境界通常为此行政级别的**最高**战力。县级可含炼体或凝气（视城镇规模），府级覆盖筑基与金丹，都级覆盖元婴与分神。

#### 表格主体：势力位阶

此表表示各势力在对应修为层级上**明面上必须具备的战力配置**。若达不到表中所列，该势力将被同一阶层的对手取代或吞并。

势力列按「宗门 — 政权」两两配对，自上而下分为四个阶层：

| 阶层 | 宗门体系 | 政权体系 |
|------|----------|----------|
| 顶层 | 三大宫 | 上三国 |
| 上层 | 六大门 | 下三国 |
| 中层 | 中流 | 列强 |
| 下层 | 教派 | 岛国 |

- 每一组内，左侧为宗门/教派势力，右侧为国家/政权势力。
- 同一修为行中两列均有值，表示该阶层势力须**同时**具备对应级别的宗门战力与政权战力。

#### 家族列
家族战力的上限随所处地域及所属国家浮动，无统一标准。当前表格以**岛国**（势力层级最低的国家）为基准，用于对比家族、国家机器、教派三者间的实力差距。
