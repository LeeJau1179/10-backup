# 今生 Notes 文件夹规范

## 定位（铁律）

`Notes/` 是**作者私人参考工作区**，仅供作者自己备忘、打草稿、做决策。它不是设定层：

- **不被 Codex 索引，不是权威内容**——真正的权威只在 `Codex/`。
- 不直接生成正文，不改写 Scene；这里的内容服务作者决策，不直接进入成果层。

## 铁律

- **单向依赖**：Codex → Notes → Scene。
- **链接**：人名、场景的写法按 `StoryLine/逆世书/AGENTS.md`「链接铁律」「通用 Obsidian 铁律」。
- **不复述机制**：奖金额度、结算口径、变身冷却与消耗等硬规则**一律以 Codex 为准**，本文只留 `[[wikilink]]` 指针，不得复述或改写。
- **冲突判定**：本文与 Codex 冲突时，**Codex 即答案，本文即错误**。
- **归位机制**：本文出现「Codex 尚未记录」的设定时，每条附「建议归位」指向应补进哪个 Codex 文件；纯剧情层内容（含具体日期、债务排期等）**留在 Notes，不回填 Codex**。
- 「待补 / 灵感」属作者 TODO，不自动转成 Codex 或 Scene，等作者指示再动。
- 修改 Notes 时直接改内容，不写来源、修订记录或日期标注。
