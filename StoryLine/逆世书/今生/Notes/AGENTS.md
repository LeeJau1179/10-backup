# 今生 Notes 文件夹规范

## 定位与分类

`Notes/` 不被 Codex 索引，不是世界观设定层，内部分两类文件：

1. **写作执行规范与校历依据**（直接约束正文写作，写前按 [[StoryLine/逆世书/AGENTS]] 核对）：
   - [[写作风格]]
   - [[AI 语录]]
   - [[卷二 大一课表]]
2. **作者私人工作区**（大纲、灵感、排期、审查报告，服务作者决策，不作为设定权威）：
   - [[本一 大纲]]
   - [[灵感]]
   - [[卷一 系统奖励时间表]]
   - [[卷二 章节划分]]
   - [[卷二 兄妹见面频率安排]]
   - [[卷二 新增人物与职业衔接]]
   - [[卷二 谢安琪相处场景安排]]
   - [[全文 一致性审查报告]]

## 铁律

- **单向依赖**：Codex → Notes → Scene。
- **链接规范**：人名、场景链接与表格转义按 [[StoryLine/逆世书/AGENTS]] 与 [[场景管理SOP]] 执行。
- **不复述机制**：奖金额度、结算口径、变身冷却与消耗等硬规则**一律以 Codex 为准**，本文只留 `[[wikilink]]` 指针，不得复述或改写。
- **冲突判定**：Notes 与 Codex 冲突时，**Codex 即答案，Notes 即错误**。
- **归位机制**：出现 Codex 尚未记录的设定时，每条附「建议归位」指向应补进的 Codex 文件；纯剧情排期（含具体日期、债务排期等）留在 Notes，不回填 Codex。
- 「待补 / 灵感」属作者 TODO，不自动转成 Codex 或 Scene，等作者指示再动。
- 修改 Notes 时直接改成最新内容，不留修订记录或日期标注。
