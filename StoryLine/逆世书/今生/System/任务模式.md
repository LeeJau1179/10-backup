# 系统任务模式（今生本 · 第一卷-转化篇 / Act 1 专用）

> 适用范围：**仅今生本的 Act 1（第一卷-转化篇）**。本卷系统为"发布—奖励制"：系统主动发布任务，奖励以现金为主。
> Act 2（第二卷）起任务形式变更（暂定）：**追认制**——主角完成某件事后系统事后追认，不发钱，只发道具卡（分身卡、跑车卡、记忆卡等）。两卷之间的机制切换本身应作为剧情事件处理（读者会注意到系统"变了"）。

***

## 一、三个钟点

| 时点       | 功能                      |
| -------- | ----------------------- |
| 00:00    | 死线：断签判定、限时任务到期          |
| 12:00    | 单次结算：单次任务奖励到账           |
| 周日 12:00 | 周期结算：全勤类奖励 + 全任务线统一"开奖" |

* 首次跑步任务期限 **12 小时**：绑定完成于周日 00:00，任务限时至当日 12:00——**死线与首次结算重合**，读者从第一笔钱起就建立"12:00 = 结算"的认知。

* 日历事实：2005-05-15 为周日。绑定（5/15 00:00）→ 晨跑 → 当日 12:00 首结，规则零例外成立。

## 二、三条任务线

### 1. 身体线 

* 口号（首发一次）：【人生赢家，怎么能没有强壮的身体。】

* 首次任务：12 小时内完成五公里 → 奖励 1000 元，当日 12:00 到账

* 周期化：首结后转【每日五公里，连续七日】，周日 12:00 结算全勤

* 断签：进度清零 + 当周奖励取消，**不牵连其他线**（01-08 既有规则）

* 加码：每满一周期解锁新维度或附带要求（如含作息达标），升级给明确播报

### 2. 财务线（开奖制）

* 口号（首发一次）：【人生赢家，怎么能没有无限的财力。】

* 开启后**每周不定时发布**，单笔限时 24 小时；不规律本身即人格（与"她"的状态有关，远期揭示）

* **开奖制**：完成时只显示【已完成，返还金额将于结算日公布】，金额周日 12:00 随周期结算统一公布

* 返还保持寒酸（参考量级：120 / 400），制造"无限财力其实很有限"的反差

* **作者侧明文伏笔**：偶发的超高返还 = 该笔消费是给苏晚（女性身份）买的东西（发卡、女装等）。许默与读者一起拼规律，系统不作解释

### 3. 爱情线 （实为学习任务）

* 口号（首发一次）：【人生赢家，怎么能没有懵懂的爱情。】

* **系统对"爱情任务"的执行方式就是发学习任务**（《励学篇》逻辑：想有颜如玉，先读书）

* 首发：【学习任务发布：熟记报关流程，明日验货。】【书中自有颜如玉。】

  * 建议任务比周海的验货邀请先到 = 系统预知失态点

  * 许默反应："这也算爱情？！"

* 链条制：完成一个，当场确认 + 自动发布下一个；奖励周日 12:00 统一结算

* 远期引爆位（二选一）：某日突降第一条真正的爱情任务；或"颜如玉"最终落在苏晚/许默自身

## 三、结算科目（系统结算单 vs 许默账本）

| 内容     | 系统结算单 | 许默账本                   |
| ------ | ----- | ---------------------- |
| 跑步线    | 跑步    | 跑步                     |
| 消费线    | 财力    | 财力                     |
| 爱情/学习线 | 爱情    | **黄金屋**（他不承认这叫爱情，无声顶嘴） |

* 结算单模板：
  【本周结算：M月D日—M月D日】
  【跑步：1000（1周）】
  【财力：120（2倍）】
  【爱情：1000（2次）】

* 账本是专用道具（日常剧情不引入）：债务栏缩短、系统栏变长 = 主角生活编年史；远期坑位——苏晚侧开销无法并账（"算谁的？"）

* 真实数字必须与正文金额链对得上（现有硬数字：首跑 1000、双周全勤合计 3000、3000−2200−200=600）

## 四、绑定礼包

* 首次结算（5/15 12:00）随奖励下发：【首次绑定礼包：增强生命形态（已解锁）。】

* 零解释。许默问"增强什么"无回答

* 虚惊场（未遂使用）插在 01-08 后：催收踩点，差点启用，对方离开——"换张脸"的逃生逻辑在此埋根

* 首次真用：01-12 酒吧（不动）

* 冷却：启用后 24 小时

* 第一次 冷却结束切换回男身后，系统提示：XX生命形态（已解锁），冷却：启用后 12 小时

## 五、系统人格红线

* **全程无对话**，只"失态"：乱码（01-03）、半秒延迟（01-12）、预知（学习任务）、口号与私货（颜如玉）

* "人生赢家，怎么能没有……"句式 = 各线首发限定，成功学腔，呼应《成功人士的七个习惯》

* Act 4《系统第一次说"我"》之后，口号句式停用或变形 = 系统转变的标志

* "无所不能"类夸大口号与《01-16 蜂毒过敏·系统并非万能》形成对撞（系统吹的牛后面都是债）

## 七、远期伏笔登记

* 颜如玉 = 苏晚 = 许默自己（"书中自有颜如玉"的最终解释权）

* 超高返还 ↔ 苏晚侧消费（系统在乎"她"）

* 爱情线真任务的引爆位（Act 3 / Act 4 候选，或留到后续本）

* 本际机制切换（第一本发布制→第二本追认制、发钱→道具卡）= 系统状态变化的剧情化呈现
