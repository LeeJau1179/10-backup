## 核心变化

- 苏然电话里走完「嘴硬手软+软一下硬回去」的撒娇切片——嘴上嫌哥哥「又乱花钱」/「又来」,手上已经买了橘子放冰箱、撒娇要随身听得手;她挂电话时只觉得哥哥「嗓子劈了 / 声音不对劲」是模糊感觉,**没有依据、没问出关键一问**(第一卷不点破)。
- 许母反向提醒「千万别碰,无底洞,害死人」后,许默心里那道「绝不能让家里知道自己欠债」的闸压得更死。
- 母亲那句「真要缺钱了,跟家里说」反而成了反作用力——他回家继续装作没事。
- 苏然那条线(撒娇切入 + 嘴硬手软)和许母那条线(心疼别人 + 反向提醒许默)在同一通电话场景内完成切换,两段关系都是嘴硬手软式表达,但内核完全不同:苏然是妹妹对哥哥的嫌弃式照顾,许母是母亲对儿子的反向担心。
- **苏然起疑的伏笔从本场挪走**(她不能在没有依据的情况下突然问「你是不是有事瞒着我」),后续放到 [[兄妹谈心·真相坦白]] 之前的某次兄妹探访 / 失联累积场合里再点破(参考 [[妹妹告状·电话打不通]] / [[兄妹探访·好久没来看我]] / [[苏然突袭·落脚点危机]])。

## 场景节拍

- 周五下午三点多，许默男身在周海外贸公司办公室核报价单，手机响——但不是妈
- **[[苏然]]（2005 暑期在滨海）先打电话来，兄妹日常斗嘴**：
  - 开场用疑问句关心：「哥，你是不是又熬通宵了？嗓子都劈了。」——**避免「吃饭」老梗**，改从「声音/熬夜」切入（许默在办公室刚核报价单，声音状态是合理观察点）
  - 许默回「没熬」→ 苏然戳穿「你糊弄别人行，糊弄不了我」——延续「识破报喜」的母题，但不必每次都拿「挺好的」三字做文章
  - 许默嘴贱回「臭丫头，管得倒宽」→ 兄妹互怼常规节奏
  - **嘴硬手软的第一支点**：苏然嘴上嫌哥哥「又乱花钱」→ 手上已经把橘子买好放冰箱了（这是她「嫌弃式照顾」的具体动作；本场兄妹电话不能只吐槽不做事，否则只剩「真嫌弃」没有「照顾」内核）
  - **小撒娇 + 许默不吃这套 + 撒娇切入目的**：苏然软一下「哥——你早点回来呗」→ 许默直接戳破「……你少来。说吧，什么计划」→ 苏然撒娇切入目的「嘿，我的随身听啊，我等得花儿都快谢啦」→ 许默答应「行，回去带给你」→ 苏然再软一下「最爱哥哥了」→ 许默无奈「……又来」——**这是嘴硬手软最完整的形状**：软（撒娇）/嘴硬（许默戳穿）/手软（为达目的的撒娇切入）/再软（最爱哥哥了）
  - 顺嘴提事：随身听念叨了一年（已通过撒娇处理）；台风别去海边
  - **苏然挂电话**：「知道了知道了。挂了。」——直接走人，**不点破、不追问**（第一卷不点破；没有依据就不问，这是她「怀疑但不追问」的边界）
  - 这场兄妹电话整体节奏：嘴硬手软、嫌弃式关心、报喜与识破报喜、**软一下硬回去**
  - **写作纪律**：
    - 苏然的开场关心句以后每通电话要换角度（吃饭/睡觉/嗓子/屋子/钱/衣服/精神 等），不能每次都「吃饭」
    - 每场苏然戏份必须同时出现「嘴硬」和「手软」——**不能只吐槽不做事**，否则就是「真嫌弃」而不是「嫌弃式照顾」；每场至少一个具体照顾动作（买东西/收拾/提醒带伞/寄东西/留挂面与辣酱 等）
    - 兄妹斗嘴的密度要控——问句不超过 3-4 个，且至少 1 个问句之外要有「陈述句+嫌弃」或「陈述句+安排」来平衡
    - **「软一下硬回去」的撒娇模式**：苏然对哥哥的撒娇不是常态，是「为达目的才撒娇」（要随身听/要礼物/要办事），撒娇前必有铺垫，撒娇后必有「最爱哥哥了」之类的退场，软完立刻转正事——这是她 18 岁妹妹 + 嘴硬人设 的最稳形状
- 不到一分钟，许默刚拿起笔，手机又响；屏幕「妈」——母亲苏文君从山南打过来
- **母亲开场寒暄（铺垫）**：问「钱够不够花？」——这一句表面是关心，底下正好踩在许默的债务伤口上
- 许默掩饰：「够用」
- 母亲说「在外面别太省」
- 顿了一下，母亲才切入正题：聊舅那边传来的「小海」——巷口老陈家在外打工的小孩，欠了好几十万，跑了
- 母亲先心疼：「那孩子也不容易，一个人在外面，没个照应」
- 母亲反向提醒：「但是那种钱——你可千万别碰。无底洞，害死人的」
- 母亲补一句：「咱家虽然不宽裕，可也别去借那些。真要缺钱了，跟家里说，听见没？」
- 许默全程只抬眉 + 停顿半拍 + 嗯 / 我知道 / 听见了 几字回应
- 母亲又扯了几句家里琐事（爸的腿、邻居修房、菜价涨了一毛），他都应了
- 挂电话后他没动，报价单还摊着，空调吹着；脑子里就一句话：不能让妈知道
- 「那个数」在心底翻来翻去，像桌上月历每月十号那个圈——
- 闪过一个意识：「下周三就是10号」——8.10 是他下一个还款日，工资 3500 对三笔 6000 的固定缺口仍在，他心里预期这次也凑不齐（"预计逾期"的内心一笔）
- 下意识摁了一下兜里的旧卡（旧银行卡是 props），又抽回手——把这一念头压下去
- 落点：他拿起笔，签了个字，接着核报价单

## 伏笔 / 钩子

- 「那个数」与桌上月历每月十号那个圈——债务现金节律第一次被亲情压力推到表层（许默的"墙上挂历"设定物在家，办公场景改用"桌上月历"作为视觉锚点）
- **8.10 临近**：本场后下一个还款日是 8 月 10 日（周三），许默已经下意识意识到这次可能凑不齐——这是「预计逾期」第一次浮上水面，下游可能直接触发「逾期」场景或在 8.10 当天/前夕爆发压力
- **苏然起疑（移到后续章节）**：本场不点破；苏然只觉得哥哥"嗓子劈了 / 声音不对劲"是模糊感觉，没有依据。**兄妹第一次真正起疑**放到 [[兄妹谈心·真相坦白]] 之前的某次兄妹探访 / 失联累积场合再点破（参考 [[妹妹告状·电话打不通]] / [[兄妹探访·好久没来看我]] / [[苏然突袭·落脚点危机]]）
- **苏然的「念叨清单」**：随身听念叨一年——后续 [[苏然生日·哥哥送礼]] 时许默攒钱买给她,嘴硬嫌他乱花钱转头显摆半个月,这是兄妹感情的细节锚点
- 母亲说「跟家里说」——日后若有一天真说出口，与今日的锁死形成回响
- 小海（巷口老陈家在外打工的小孩）首次出场，可作后续远方同处境角色的伏笔
- 兜里的旧卡（许默 props）——挂电话后下意识摁了一下又抽回手，债务焦虑第一次被身体小动作外化
