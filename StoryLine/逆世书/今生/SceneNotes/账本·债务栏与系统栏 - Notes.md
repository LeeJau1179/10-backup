## 来源

作者对话（2026-09-15 / 09-16）：账本（开场出现过）作为专用道具，与钱线节奏配合。

修订来源二（2026-09-16，作者对话）：**记账的形式与核对口径一律以开场 [[生日谎言·老周递烟]] 那一页为准**，本场此前的写法（巴掌大硬皮本、工作室散伙后捡回来、最后一笔停在两年前、叙述式记债、抽屉最底压杂志）全部作废。同轮一并修正金额核对错误：借款机构的 2200 是**每月纯利息**，不是一次性逾期款（依据 [[许默]] 人物卡「每月压力：三笔债务合计6000元」与 [[五公里验证·生日与催收]] 的"您这期应付的两千二"），原文的「三笔债，一个月要出三千八」「差三百」全错。

## 核心变化

两年来只往一个方向掉的那本账，第一次多出一栏进来的钱。[[许默]]另起空页画竖线分栏，左「欠」右「系统」，**两栏都沿用开场那一页的一行一笔记法**；右栏合计三千五、追平他一个月工资，可六月十号那三笔照旧是六千，缺口还是两千五——他把「不够」写在右栏最下面。

## 记账形式（统一基准：开场 [[生日谎言·老周递烟]]）

> 本场是账本第二次露面，**一切写法向开场看齐**，物件与记法见 [[账本]]。

| 项 | 基准（开场） | 本场必须照做 |
| --- | --- | --- |
| 物件 | 两块钱的笔记本，深绿色封皮，边角已经卷了 | 同。**不得再写**巴掌大、硬封皮、边角磨得起毛 |
| 来历 | 自己买的，两年来一直在用，每月发工资后记一次 | 同。**删除**"工作室那阵子记账用的，散伙后扔过一回又捡回来""最后一笔停在两年前" |
| 取放 | 从**抽屉最里面**摸出／收回 | 同。**不写**"抽屉最底下"（压旧杂志可保留） |
| 笔 | 圆珠笔**夹在记着的那一页**里，翻开即取 | 同。**不写**"把笔帽咬开"这类来路不明的动作 |
| 行格式 | 全角缩进两格，字段用全角空格分隔：`债主　金额　状态` | 同 |
| 状态记号 | 已付标「**已**」，不认的争议加价标「**？**」（紧跟金额，无空格） | 同 |
| 排序 | 已付的在前，未付／争议的在后 | 同，四行顺序与开场完全一致 |
| 只记债 | 代练进项不写，吃饭的钱不写 | 本场是**第一次破例**：要把"两年来只记出去的钱"点明，再写进来的那一栏 |

- 分栏是本场的新动作（[[账本]]设定已确立）：另起**空页**画竖线，左「欠」右「系统」；**右栏同样一行一笔**，格式为 `日期　科目　金额`。
- 右栏科目**照系统结算单抄**（跑步／财力／身体／爱情），只有「爱情」被他划掉改成「黄金屋」——**改名只改这一个**，其余照抄，科目对照见 [[本一卷一·系统任务设定]]「结算科目与结算单」。原文把 5.22 那笔写成"消费"是错的，结算单上是**财力**。

## 场景节拍

- **"黄金屋"落地**：他照系统的叫法写下"爱情"，随即划掉改成"黄金屋"——账本与系统结算单的科目名从此分家。
- 两周系统收入＝一个月工资（3500），这个对照是他第一次意识到量级。
- **小算式（已修正）**：每月十号三笔＝程辉2000＋借款机构2200＋高利贷1800＝**6000**，工资3500，**固定缺口2500**；还完逾期的2200后右栏剩1300，10号前只剩一次结算。缺口没变，变的是**这两千五头一回不用从零开始凑**——"第一次"落在这里，不落在"差三百随手就能补"。
- 右栏末尾留白写"不够"：钱在变多，1700 的争议加价和每月六千还压着。
- 账本收回**抽屉最里面**、压旧杂志——不能让人看见（掉马风险的物件侧）。

## 伏笔

- 账本是**专用道具，日常剧情不引入**，只在钱线出现拐点时露面。
- 远期坑位：[[苏晚]]侧开销无法并账（"算谁的？"）。
- "不够"这一行对应 [[酒吧逃堵·首次变身]] 的钱线前提——还完逾期、手上有余额但不敢动。
- 1700 争议加价指向 [[催收闹公司·许默反击]] 与 [[正面交涉·非法催收终结]]。

## 注意


- 本场发生在 5/29 结算当天下午，早于 6/3 的银行与转账动作；结尾只说"这两天先去一趟银行"，**不写"明天"**，以免与 [[酒吧逃堵·首次变身]] 里 6/3 才去银行的记述打架。
- 左栏四行与开场完全相同（程辉2000已／龙哥1800已／借款机构2200／龙哥1700？），因为 5 月的付款结构到 5/29 没有变化；他是**抄到新页上**，不是记新账。
- 金额链见 [[本一卷一其他内容]]「卷一金额链校验」：系统累计3500 → 6/3 还2200、转妹妹200 → 余1100。
