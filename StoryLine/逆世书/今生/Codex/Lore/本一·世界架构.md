# 世界架构（第一本 · 现代篇）＝人族源界

> 本文是现代社会相关设定的统一入口，也是**源界规则的唯一权威**。

## 世界定位

现代社会属于**人族源界**。它由人族大能为保存本源族群而创造，是封闭保存族群本源血缘与灵魂烙印的世界。"源"指保存族群的**本源血缘与灵魂烙印**。每个源界原则上只容纳一种本源物种，科技是人族在低灵环境中利用基础秩序法则发展出的独立道路。

## 基础规则

| 规则 | 表现 |
| --- | --- |
| 单一物种 | 原则上只允许纯粹的人族长期生存 |
| 最低循环 | 仅保留人类生存、繁衍、基础轮回与文明发展所需的能量 |
| 外族排斥 | 外族和高阶生命进入后会持续流失力量，难以维持原本形态 |
| 坐标隐藏 | 没有血缘锚点或特殊仙器，难以定位和进入 |
| 科技道路 | 低灵环境限制仙法，却有利于稳定研究和利用基础秩序法则 |

## 与灵界的时间差

- 人族源界能量循环极低，时间流速较慢。
- 当前剧情换算：现代社会1天约等于晟朝灵界1年。
- 两界始终向前运行，不存在自由回到过去的能力。


## 进入源界的目的（此行动机）

1. **妹妹唤醒姐姐**：[[一伶]]以系统状态跟随[[主角]]回到源界，通过任务、变身与记忆碎片帮助姐姐的高阶主魂和现代人格层重新合一。
2. **姐姐救回妹妹**：[[苏晚]]的肉体并未消失，而是随妹妹之魂封存在系统中。姐姐恢复记忆后必须完成肉体分开、灵魂分开与关系归还，让妹妹以完整的人重新回到苏家；这构成第一本“救妹妹”的核心。
3. **走完各自的人生**：姐姐继续认领[[许默]]与[[程辉]]、[[苏然]]等真实建立的羁绊，并重新面对[[林北川]]；妹妹则取回[[苏晚]]的家人与身份。恢复前世不抹去源界生活。
4. **借时间差完成恢复**：灵界中的修为与仙体仍需漫长修复，主思维先回到源界生活；源界1天约等于晟朝灵界1年，灵界恢复可在后台持续进行。

## 暗线 · 源界升格（灵气复苏）

- [[主角]]回源界后，以本体推动"**源界升格 → 灵气复苏**"。
- 作用：① 解禁后续法术线；② 让三仙器到源界后能释放真正能力；③ 为日后[[主角]]脱离女身、与仙界本体在源界**归一**铺垫。
- **暗线**，仅背景点到，最多恢复本体前与 [[林北川]] 对话带过。

### 源界升格前置研究

- [[林北川]]与源界高层保持小规模生命科学和异常能量研究，入校前只作为其现代身份与医疗能力的暗线，不在校园内公开开课。
- 姐妹分魂、仙体归一后，相关研究可在第三卷成为源界升格的现实接口；学生与普通人仍只接触受控现象，不会立即得知仙凡对接的完整真相。
- 受控现象包含**国家表层**：公众感知的国势提升、传统文化复兴、中医/影视产业扶持等世俗现象，是修真界来人在源界的表层痕迹——初读为时代新闻，回看为升格先兆。

## 现代篇限制

- [[主角]]修为恢复须循序渐进，否则会遭到源界排斥。
- 仙器必须以低能耗形式逐步苏醒。
- 三仙器的能力来源仍分别对应精神／灵魂与身份、肉身／恢复、技巧／操作；在第一本中三者被[[一伶]]统一为一个系统整体，不独立显形，也不分别接管人物身体。
- 现代篇的力量成长应以"受限恢复"为核心。
