# 世界架构（第一本 · 现代篇）＝人族源界

> 本文是现代社会相关设定的统一入口，也是**源界规则的唯一权威**。

## 世界定位

现代社会属于**人族源界**。它由人族大能为保存本源族群而创造，是封闭保存族群本源血缘与灵魂烙印的世界。"源"指保存族群的**本源血缘与灵魂烙印**。每个源界原则上只容纳一种本源物种，科技是人族在低灵环境中利用基础秩序法则发展出的独立道路。

## 基础规则

| 规则 | 表现 |
| --- | --- |
| 单一物种 | 原则上只允许纯粹的人族长期生存 |
| 最低循环 | 仅保留人类生存、繁衍、基础轮回与文明发展所需的能量 |
| 外族排斥 | 外族和高阶生命进入后会持续流失力量，难以维持原本形态 |
| 坐标隐藏 | 没有血缘锚点或特殊仙器，难以定位和进入 |
| 科技道路 | 低灵环境限制仙法，却有利于稳定研究和利用基础秩序法则 |

## 与灵界的时间差

- 人族源界能量循环极低，时间流速较慢。
- 当前剧情换算：现代社会1天约等于晟朝灵界1年。
- 两界始终向前运行，不存在自由回到过去的能力。


## 进入源界的目的（此行动机）

- 姐妹互救、转生重构和返回后的主动安排见[[本一·穿越与分身设定#重构与短期回归]]。
- 姐姐继续承担[[许默]]与[[程辉]]、[[苏然]]等真实建立的羁绊，并重新面对[[林北川]]；妹妹取得独立生命与自主选择权。恢复前世不抹去源界生活。
- 修为与仙体可借两界时间差持续恢复，但不得把幕后修复混同于姐妹尚未回归。

## 源界升格与长期留守

- 姐姐最终以[[苏依伊]]原身回归许家，长期留在源界推动升格；她留下既因为真实关系，也因为主动承担这个世界的未来。
- 升格使低灵环境逐步改变，为法术恢复、仙器释放真正能力和原身稳定存在提供条件；具体阶段与仙体归位的适配过程待细化，不直接恢复全部力量突破排斥限制。
- 前期沿用国家表层与研究背景伏笔，后期从背景进入主角的主动选择。第一本结尾升格启动还是完成仍待定，当前新增场景仅占位，不默认升格已经完成。

### 源界升格前置研究

- [[林北川]]与源界高层保持小规模生命科学和异常能量研究，入校前只作为其现代身份与医疗能力的暗线，不在校园内公开开课。
- 相关研究逐步成为源界升格的现实接口；不得把姐妹分魂与仙体归一提前至第三卷；学生与普通人仍只接触受控现象，不会立即得知仙凡对接的完整真相。
- 受控现象包含**国家表层**：公众感知的国势提升、传统文化复兴、中医/影视产业扶持等世俗现象，是修真界来人在源界的表层痕迹——初读为时代新闻，回看为升格先兆。

## 现代篇限制

- [[主角]]修为恢复须循序渐进，否则会遭到源界排斥。
- 仙器必须以低能耗形式逐步苏醒。
- 器灵平时不外显，只在强化或主动保护时才有反应，同类器灵这时才感知得到。例：游艇上[[一伶]]护住了[[苏晚]]，[[玄玦]]因此察觉到她身上的器物气息（[[01-39 游艇遇袭·力量层级反转|游艇遇袭·力量层级反转]]）；圣诞[[林硕]]被撞时[[玄玦]]护主，[[林岚]]借[[昭瑶]]找到了开车的人（[[02-123 开车的人·林岚收尾|开车的人·林岚收尾]]）。
- 三仙器的能力来源仍分别对应精神／灵魂与身份、肉身／恢复、技巧／操作；在第一本中三者被[[一伶]]统一为一个系统整体，不独立显形，也不分别接管人物身体。
- 现代篇的力量成长应以"受限恢复"为核心。
