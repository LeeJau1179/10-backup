# 本一·分卷主轴

| 卷 | 定位 | 主轴 |
| --- | --- | --- |
| 卷一 | 形态之变 | 这个身份，她肯不肯用 |
| 卷二 | 身份之变 | [[苏晚]]是借来上学的身份，还是她自己的生活 |
| 卷三 | 情感之变 | 别人替她安排，还是她自己选 |
| 卷四 | 待定 | 待定 |
| 卷五 | 真我归位 | 待定 |

女身与姐妹线在各卷的作用：第一卷让[[主角]]习惯使用女身，第二卷让她以[[苏晚]]正式入学，第三卷认亲与归家承接妹妹的真实记忆，第四卷推进求真、关系选择与妹妹意愿的明确表达，第五卷完成约定重议、姐妹独立与原身归位。
