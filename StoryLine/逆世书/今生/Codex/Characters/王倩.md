# 王倩

## 关系

- 对[[林硕]]：暗恋＋崇拜＋攀附搅在一起的心思；他对她始终冷脸、没有回应，元旦舞会他带的女伴又是[[苏晚]]
- 对[[陈思思]]：同班同学；以[[苏晚]]室友的身份跟她说[[苏晚]]的事，听着像替[[苏晚]]说话，话里夹着评价
- 对[[郑伟]]：替他的活动做兼职，图钱和履历；被他坑了之后，她清楚是谁撤的支持，却认定[[苏晚]]露个面、吃顿饭就能免掉她的损失，把账记到[[苏晚]]头上，觉得“她欠我的”。短暂冷脸后表面恢复，背地里从谋利转向报复
- 对[[苏晚]]：表面亲近，内心嫉妒；她把[[苏晚]]与[[周扬]]、[[林硕]]的朋友往来曲解为脚踏两船

## 黑化弧线（恶意逐级生长）

| 级 | 时点 | 落点 |
| --- | --- | --- |
| ① 消息价值 | 2005.9（09-16） | 校网帖里有人出价求联系方式，[[孟夏]]念出价给她听——有人出钱买的东西，就能卖；大一只把宿舍里的事说给外人听、偷拍留着，还没收过钱 |
| ② 心动与嫉妒 | 2005.9-2006.5 | 对[[林硕]]的心思（暗恋＋崇拜＋攀附），最早一格＝开学第一个周日他送[[苏晚]]回宿舍（已在食堂见过他，此次进一步留意楼下等人与两人关系）；元旦舞会他带[[苏晚]]当女伴，嫉妒摆上台面；他对谁都冷脸，人不在学校还记着[[苏晚]]的生日、礼物照样送到 |
| ③ 恶作剧 | 2006.9 大二军训 | 看不惯她出风头，从背后推她上台（挂在军训晚会，回看时成立） |
| ④ 金钱诱惑 | 2006 秋起 | 开始收钱：卖宿舍消息、倒卖室友物品、卖私房照；到[[林岚]]来买消息时这几样都已在做 |
| ⑤ 引爆 | 2007.4 | 蜡烛表白后[[周扬]]在背地里替[[苏晚]]挡事善后，她在人群外看着；次日发帖——一边吊着金龟婿，一边让别的男生替她出头 |
| ⑥ 无望后的报复 | 2007春 | 对[[林硕]]始终无望，恨意转向[[苏晚]]；把她与[[周扬]]、[[林硕]]的朋友往来歪曲成恋爱纠葛，脚踏两船帖＋偷拍 |

1. 对[[林硕]]无望后沉迷金钱，交往过很多男友（多为纨绔）
2. 倒卖升级：大二上开始收钱，先卖宿舍消息，再卖宿舍其他人的物品，再用手机偷拍室友照片卖钱；2007年4月起在校网连发匿名帖攻击[[苏晚]]。她的消息买家名单里有一个她不知道底细的人——[[林岚]]，买消息的同时暗中摸清了她的全部买卖，还大价钱买断她手里的私房照、要求"只准给我，不准发给别人"；她满口答应，转头照卖不误
3. 私密照片不露正脸、不涉及裸露，只截取家居服、肩颈、腿脚等不应外传的私人状态；偷拍兼有金钱与报复双重动机。2007年春宿舍楼里"有人喊有小偷"——众人自查才发现失物，交易链与偷拍、匿名帖一并败露；她不知道这声喊是[[林岚]]暗线安排的。床位由[[林岚]]补入
