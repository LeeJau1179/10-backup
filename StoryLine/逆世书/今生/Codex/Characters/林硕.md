# [[林硕]]

## 基本信息
- 身份：[[林北川]]之子，晟朝皇子；**生母为[[林北川]]另一妃子**，与 [[林岚]] **同父异母**
- 年龄：实际年龄20余岁；现代身份为2005年入学的大学新生（2006年5月离校）
- 出生背景：**幼年继位**：父[[林北川]]为寻[[主角]]离灵界，襁褓继位、朝堂长大
- 状态：穿越至人族源界，有器灵傍身
- 性格：
1. **冰冻脸**：看不出喜怒哀乐 —— 脸是壳不是面瘫，底下有情绪，靠眼和语气出口
2. **眯眼**：唯一面部动态，上位者压迫 / 审视 / 看穿；垂眸低频，防御性藏，罕见露裂痕时用
3. **早熟**：决断、手腕、担当全在 —— 被逼而非从容
4. **放荡不羁**：对父亲塞来的江山 "我偏不"，态度反叛；**非纨绔**（底子改不掉）
5. **家庭封闭**：父亲偏心、长期缺席与替他安排人生构成行为动机，也是他拒绝他人介入的关系心结；重点写他不愿谈、不愿回、不接受帮助，**不写成反复发作的创伤记忆**
6. 睡浅：一点动静就醒

## 标识 / 动作

- **冰冻脸 + 眯眼 + 短促疑问句**（"嗯？你不去？那你呢？"）
- 短句规则：对峙 / 施压 / 看穿时用，控制频率；语义分层（"嗯？" 施压／"你不去？" 点破／"那你呢？" 反将一军）

## 失忆期开关

- 失忆 = 冰冻脸融化、眯眼消失、短句变长句大白话；恢复记忆 = 四项全部回归
- 失忆丢的是个人经历，常识与生活技能在线——“我是失忆，不是变痴呆”（[[打工抵债·骗局变收留]]里一眼看穿[[苏晚]]例假、帮备物品）；会开车（08-04 晚替醉酒的老周代驾，开的是老周的车，见 [[双号误接·通讯升级]]）
- 失忆期打工形态：先工地搬砖（日结一百，08-01 起，见 [[打工抵债·骗局变收留]]、[[吃苦瞒不住·代练上手极快]]）；08-04 台风前雨工地停工，改送餐（日结一百，见 [[双号误接·通讯升级]]、[[账在心里·以后就是合租]]）

## 情感定位

- 喜欢[[苏晚]]，感情指向[[主角]]本人，不只源于女性外貌；第一本保留感情可能性，不以纯兄弟关系收束。
- [[林硕]]承担“最早喜欢[[主角]]，却注定无法在一起”的爱而不得线。
- **认知**：他始终认定[[苏晚]]才是真人身份，[[许默]]只是掩饰身份——[[主角]]以[[许默]]身份坦言男身，他也只当是拒绝的嘴硬（[[冰棍试探·坦言男身]]）。

## 入学安排

- 与姐姐[[林岚]]同一年（2005年9月）以大一新生身份入学
- 交出[[苏晚]]失踪前的真实旧证件，并办妥当期有效身份
- 直接运作正式本科生入学，不安排校内考核。面对[[主角]]追问，他用“给学校捐了一栋楼，还帮市里建了一片岛”解释为什么学校愿意放行
- 与[[沈砚]]同宿舍，但基本不住宿舍，因此这层关系不会在报到日自动把[[沈砚]]带到[[苏晚]]面前

## 对[[苏晚]]的家庭披露边界

- 卷一[[陪读方案·苏晚身份材料齐备]]：[[苏晚]]拿到身份证、银行卡与录取通知书后已经问过家在哪、家里做什么、高中经历、如何来到滨海和上沪、家里有几口人。[[林硕]]给出现实轮廓：家里生意与投资都做，落脚处很多，不给固定地址，求学和学籍由家里安排；家中有父亲和一个同父异母的姐姐，父子有矛盾，姐姐多数时候站在父亲一边。母亲不谈。
- [[下次我请·一顿饭变成下一顿]]：关系加深后，[[苏晚]]追问他为何知道双身份异常却不害怕。[[林硕]]只说见过无法解释的事，并以「问了你也不会说，所以不问」表达接受，不透露灵界经历。
- [[烧烤·你没欠我]]：[[林硕]]第一次谈到父亲长期缺席、责任过早落到自己身上，以及姐姐理解父亲却未必理解他；[[苏晚]]开始想帮助他缓和兄妹与父子关系。
- [[不回家·把你姐电话给我]]：[[苏晚]]从劝说升级到索要姐姐电话、提出代为沟通。[[林硕]]拒绝联系方式，却不再否定她以后可能介入。
- [[高端舞会·苏家兄弟初见苏晚]]：[[林硕]]第一次接受[[苏晚]]陪自己面对来自家里的安排，但仍不透露家人真实身份。
- 硬边界：在离校前不说父亲是[[林北川]]、姐姐是[[林岚]]，不给住址、电话等可追查入口，不透露皇子、灵界、[[玄玦]]、父亲寻找[[主角]]或林氏调查[[苏晚]]。因此[[苏晚]]了解他的感受与家庭结构，却在他失踪后依然找不到具体的人。

## 第二卷定位

- [[苏晚]]入学后，[[林硕]]替[[主角]]打点两个身份的事——他心里始终认定[[苏晚]]才是真的那个；面对[[沈砚]]的追求会产生情绪波动，但不主动破坏关系。
- 元旦校园舞会邀请[[苏晚]]同行，先形成“校花校草”误会；大一下受[[林北川]]安排代为参加高端舞会，再次带她作为女伴出席（[[元旦舞会·女伴误会与林岚献唱]]、[[高端舞会·苏家兄弟初见苏晚]]）
- 入学一个多月后，以「你头发总掉下来」为由送[[苏晚]]一枚普通发卡；她收下后仍道谢、问价并提出回请。两个多月后她在元旦舞会自然戴上，已经不再想起结算。圣诞当天两人原定吃饭、看灯，[[林硕]]却在蓄意车辆冲撞后只回一句「没事」，[[苏晚]]从答非所问中察觉异常，直接去照顾他（[[发卡·你头发总掉下来]]、[[没事·他没有赴约]]）。
- 在十一双身份行程中提供有限配合，但[[主角]]能够自行完成两边安排；2006年5月初高端舞会散场当夜被[[林北川]]送出国远离——姐姐在舞会上确认了[[主角]]的身份，他从头到尾不知情，自此在校内不再出现（[[舞会散场·林硕被紧急送走]]）。被送走时他大概猜到了原因，谁都没说破——父亲来此的目的、谁有能力彻底挡下自己，他此前已经查清，只是从没对任何人挑明。

## 第二卷关系递进（[[苏晚]]视角）

### 总体弧线

第二卷不写成突然心动，而写成关系边界在日常配合中逐渐消失：**结算人情 → 征求意见 → 默认同行 → 身体习惯越界 → 失踪后习惯落空**。[[苏晚]]前期始终用“老板照顾员工”或“兄弟互相帮忙”解释两人的相处；后期重新审视时，才发现[[林硕]]早已进入自己的行程、决定和身体习惯，关系已经超出这些称谓能够解释的范围。

### 递进层次

1. **接受安排，仍要结算**：起初由[[林硕]]安排接送、路线、用品和生活琐事，[[苏晚]]跟随并接受照顾，但会明确道谢，用“谢谢老板”、回请或记账感维持边界。此时递水、披外套、带饭等行为都被她理解为工作关系或兄弟照应。
2. **主动提出，先问意见**：关系熟悉后，[[苏晚]]开始把自己的兼职、采购、出行和校园安排告诉[[林硕]]，会问“你觉得这样行不行”“你有没有空”。她不是请他替自己决定，而是第一次主动把他的意见和时间纳入规划；消息回复更快、分享的小事更多，感谢仍有，但不再像结账。
3. **直接安排，默认他会跟随**：再往后，[[苏晚]]会直接告诉[[林硕]]时间、地点和要做的事，让他来接、陪同或一起处理；[[林硕]]自然照办。她不再为每次照顾郑重道谢，而以互相配合为默认前提，也会顺手照顾他的忌口、习惯和行程。
4. **身体先于意识承认亲密**：她会下意识接过投喂和递水，走路或落座自然靠近他，累时能靠在他身上睡着，对偶然触碰不再警觉；[[林硕]]把冰淇淋递到嘴边时，她可能边说话边自然张口，动作完成后才意识到距离不对。两人还会出现不用说完就能接上动作、语气和节奏的默契。
5. **重新审视并试图退回兄弟**：外人的误会、室友对关系的观察，以及她偶然看见[[林硕]]注视自己的方式，使[[苏晚]]第一次意识到这些动作并不属于普通老板、员工或兄弟。她仍会嘴硬，并尝试用男身和“咱是兄弟”重新划线；冲突来自界线早已在长期相处中被双方共同跨过。
6. **失踪让默认变成落空**：[[林硕]]突然离开后，[[苏晚]]不是先得出“喜欢”的结论，而是在生活中不断遇见空位——消息无人回应、计划里少了默认同行的人、习惯性侧身或伸手时没有人接。她由这些落空反向确认：自己早已把他放进生活，而不是只把他当作提供帮助的老板或兄弟。

### 表现原则

- 以反复出现的小动作承载变化。同一组“递食物／递水”“并肩或靠肩”“共同安排行程”，每次出现都让感谢更迟、解释更少、配合更自然。
- [[苏晚]]在[[林硕]]身边的情绪变化以安全感和卸下防备为主，不依赖频繁脸红、偷笑或直白思念；她可以沉默、犯困、分享琐事，也会在他突然冷淡时烦躁，却先解释成“今天配合不好”。
- 外表变化只作低频辅助。[[苏晚]]本来就在经历爱美与自信成长，不能把普通打扮都写成恋爱信号；更合适的是选好衣服后下意识问[[林硕]]意见，或后来无意选中他曾说适合自己的颜色。
- 关键日常应在当时真实发生，后续重新审视时只闪回动作或感觉，不用大段回忆临时补足感情证据。
- 共身期的行动与感情体验属于姐姐主导的[[主角]]，妹妹独立后不自动继承这段关系。
