# [[周扬]]

## 与[[主角]]的关系

- 初见：大一开学后第一个周六经[[林硕]]介绍认识，晚上教她骑仿赛（[[02-80 仿赛夜骑·谢了兄弟|仿赛夜骑·谢了兄弟]]）；此后三人每周五一起骑车
- 不知道[[许默]]的存在；与[[林硕]]是同学，学校登记的宿舍同一间

## 关系进程

| 时间 | 阶段 | 内容 |
|---|---|---|
| 大一 | 朋友过场 | 经[[林硕]]认识，三人骑车、开黑，按朋友相处 |
| 大二上 | 暧昧与划界 | [[宋雨桐]]托牵线后，他的关注逐渐显出；她先察觉，旁人再证实；她划界，他道歉收敛，两人继续有边界的往来 |
| 大二寒假 | 照顾与信任 | 他留沪照顾不适的[[苏晚]]，尊重她拒绝进屋的边界；她接受帮助并回请，之后他送她回[[山南]] |
| 大二下 | 心动与选择 | 她先发现自己想主动靠近，再面对正式表白；室友帮助区分感激与喜欢，交往由她自己决定 |
| 大二下—大三 | 正式男女朋友 | 双方知道未来不确定，仍选择认真、排他地交往；暂不公开，尊重私人边界，安排有变及时沟通；有快乐的日常，也有谈成的分歧和没谈完的分歧 |
| 大三末 | 冲突与分手 | 他把交往告诉家里，见家人及未来安排引爆分歧；双方确认生活需要不同，和平分手 |

## 兄弟边界与主动选择

- 大一双方按朋友相处。
- 她用既有兄弟经验理解关系；大二上互动变化时自行察觉、设限，旁人帮助证实他的意图。
- 她主动找他，是因为喜欢共同活动和这个人的陪伴。
- 正式交往建立在她已有好感且主动愿意靠近之上；她坦诚未来不确定，也认真承担伴侣的位置。
- 分手时，她需要面对未谈清的未来分歧，他也需要面对替双方决定、越过约定的责任。
- 经历这段关系后，她对后续感情的谨慎来自更认真衡量自己能承诺什么。
- 兄弟相处的语言边界见[[林硕#受助后的语言边界]]。

## 感情走向

- 他的照顾出于善意，也愿意为关系负责；与[[苏晚]]的不合来自双方对亲密关系位置的需求不同。
- 隐约察觉[[苏晚]]心里有自己够不着的地方，认定是她还没习惯被人照顾，于是照顾得更多、更用力；直到分手时才承认那不是照顾能填满的，自己说破（[[03-228 家人邀约·被规划好的以后|家人邀约·被规划好的以后]]）。
- 认定关系是认真的，就按传统观念让它“名正言顺”：虽然答应过不声张，还是把交往告诉了家里，在他看来家里不是“外人”；[[苏晚]]直到家人提出见面时才得知，由此起冲突（[[03-228 家人邀约·被规划好的以后|家人邀约·被规划好的以后]]）。

## 行为方式

- 做事：看到问题就上手，机器、车、门锁，不问也不先征得同意。
- 帮人：不等[[苏晚]]开口就替她做；问了也不等回答（“你是不是不舒服？走，去医院。”），被拦下会不服气。
- 被帮：坦然接受，不算账，觉得兄弟、朋友之间本该这样（借[[林硕]]的车不觉得欠了什么）。
- 说话：话不多、直，认定的事不绕弯。
- 冲突：会道歉，只为方式道歉，不收回心意（他来道歉·一步不退）。
- 感情：把自己设想的生活当成两人共同的规划，按传统观念让关系“名正言顺”。

## 剧情作用

- 卷二只作朋友过场；卷三大二上暧昧，大二下由姐姐主动选择开始正式交往，大三末因家庭冲突分手，两人确认彼此不合适走向 BE
- 感情对象从始至终都是姐姐。[[周扬]]不与妹妹单独相识、对话或建立情感事件；姐妹分开前，他与姐姐已确认未来选择不合适并结束交往，妹妹[[一伶]]不继承这段关系。
