# 逐层检查清单

每层只列本书反复出过的问题。对照 `AI 语录.md` 的案例判断，不机械套用。

## 一、剧情与现实逻辑

- 场所结构、时代条件对不对：阶梯教室椅子固定、宿舍楼层与浴室位置、2005 年前后的通讯和物价。
- 事件因果是否成立：人物为什么此时做这件事，结果有没有落地。
- 有没有凭空发明的制度、流程、手续。
- 设定规则（变身冷却、共身传导、身份限制等）是否与 Codex 一致；正文里不复述规则，也不写“男身／女身”这类术语。

## 二、人物行为与对白

- 每句台词有交流目的，接住上一句；答非所问必须有原因（回避、嘴硬、故意曲解）。
- 开了话头要有下文；没有下文就换话或删掉。
- 说话人从哪儿得知台词里的信息；得不到就改成问句或删。
- 生熟分档：同一人对生人、熟人说话不同，按 `写作风格.md` 第九节核对。吐槽符合人物当时的认知。
- 人设靠人物做的事体现，不靠配表情。群体场面只写最有用的一个人的反应。
- 主角的判断用确定语气直写，哪怕判断是错的；不写“以为／可能／兴许”式猜测腔。

## 三、连续性

| 线 | 核对什么 |
| --- | --- |
| 时间 | 日期、时刻、昼夜、事件先后，与前后场和 `storyDate` 是否接得上 |
| 空间与行动 | 人物在哪、怎么移动、物件位置 |
| 人物与知情范围 | 谁在场、身份与称谓、代词“他／她”随当前形态和说话者认知 |
| 物件与状态 | 伤势、疲劳、钱数、关键物件的持有和消耗 |
| 专名 | 人名、地名、组织名、称呼是否稳定 |

证据不足时标「待核实」，不把推断写成事实。

## 四、叙述与情绪

- 已经由动作、台词表现的情绪，不再解释一遍；不写“她终于明白了”式升华。
- 作者的创作解释没有混进正文旁白。
- 暗示读者能从当前场景或近处前文读出来；读不出的远景、灯光、空镜头删掉。
- 填充动作和流水账：动作要改变互动或推动情节；次要过程一句带过；陈设只写有用的一样。
- 闪回由当下的事触发，符合主角真实经历，一句交代清何时何地。
- 体感、声音一句点到，不展开形容；不空写声音。
- 场景完成任务就收，不画蛇添足。

## 五、措辞

- 不用“什么”“某”虚指装口语。
- 不用“没急着 X”“没再 X”“没计较 X”这类说明式否定动作。
- 台词说成人话，不省字省成病句，不生造缩略词。
- 对照 `写作风格.md` 第十一节量化指纹：段落、句长、对话标签、标点是否明显跑偏；习惯动作（“看了一眼”“忽然”“没说话”“愣了”）不再加码。
